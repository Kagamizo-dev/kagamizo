# twin: the status page as a map of the server

Read CLAUDE.md first. Kind: world.

The status page's view becomes a rendering of the twin's real world, not a drawn one.

1. A Rust crate `modules/twin/_tiles` on fastanvil (`twin.adoptions.fastanvil`, owengage/fastnbt at 60c7ee0d, MIT). It renders /var/lib/twin's region files to 256 px PNG tiles at three zoom levels.
2. A host timer runs it every 10 minutes. The tiles are served to the status Worker through the tunnel at a path behind Access, as chat and harness are.
3. A Bevy WebAssembly crate `modules/twin/_view` (bevy, bevy_ecs_tilemap and rs-tiled adoptions) shows the tiles with pan, pinch zoom and a corner minimap. It overlays the Tiled districts and rooms from the declarations, and shows the stats JSON beside the map.
4. It replaces the World section's drawn canvas (modules/twin/world.nix and modules/site/default.nix). The HTML shell is generated by Rust, with no inline script.
5. It passes the page check at 390 and 1280 px.

Study BlueMap, squaremap and Pl3xMap with REA for tile layout and overlays; their code is Java and is not vendored.
